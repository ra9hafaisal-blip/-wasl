# نشر وَصْل كرابط عام عبر Laravel Cloud

العنوان `http://127.0.0.1:8000/` يعمل على جهاز التطوير فقط. للحصول على رابط يفتحه الآخرون، ارفع المشروع إلى مستودع Git خاص ثم اربطه باستضافة تدعم Laravel.

## تجهيز المستودع

قبل الرفع، تأكد أن `.env` و`database/database.sqlite` غير موجودين في Git. أُضيفت قواعد استبعاد قاعدة SQLite المحلية إلى `.gitignore`؛ لا ترفع ملف البيئة أو كلمات المرور أو قاعدة البيانات التي استخدمتها محلياً.

من مجلد المشروع في PowerShell، أنشئ مستودعاً محلياً وادفعه إلى مستودع GitHub خاص أنشأته:

```powershell
git init
git add .
git status
git commit -m "Prepare Wasl for deployment"
git branch -M main
git remote add origin <private-repository-url>
git push -u origin main
```

قبل `git commit`، افحص `git status` وتأكد من عدم ظهور `.env` أو `database/database.sqlite`.

## النشر

1. أنشئ تطبيقاً في Laravel Cloud واربط المستودع الخاص والفرع `main`.
2. اختر PHP 8.5، ثم أضف قاعدة MySQL أو PostgreSQL من لوحة Cloud. لا تعتمد على ملف SQLite المحلي في الاستضافة.
3. اضبط متغيرات الإنتاج: `APP_ENV=production` و`APP_DEBUG=false` و`DB_CONNECTION=mysql` أو `pgsql` حسب القاعدة. اربط `APP_URL` بعنوان التطبيق الذي تمنحه الاستضافة. المنصة تضيف بيانات اتصال قاعدة البيانات و`APP_KEY` عند تجهيز الموارد.
4. استخدم أمر البناء `composer install --no-dev && npm run build` وأمر النشر `php artisan migrate --force`.
5. بعد اكتمال النشر، افتح الرابط الذي تعطيه المنصة وتحقق من الرئيسية والتسجيل وتسجيل الدخول وإضافة بطاقة والخصوصية وصفحة الشبكة.

## بيانات العرض

قاعدة الإنتاج تبدأ منفصلة عن `database/database.sqlite` المحلية؛ الترحيلات تنشئ الجداول فقط ولا تنقل البطاقات الحالية. إذا أردت بطاقات العرض الموجودة في `QuoteDemoSeeder`، شغّل بعد النشر:

```powershell
php artisan db:seed --class=QuoteDemoSeeder --force
```

لا تنفّذ seeder قبل مراجعة البطاقات وأسماء العرض التي ستظهر للزوار. أما نقل البيانات المحلية الفعلية فيحتاج تصديراً واستيراداً منفصلين بعد مراجعة بيانات الحسابات والخصوصية.

## نطاق هذه الخطوات

الخطوات تجهز النشر لكنها لا تنشئ حساب الاستضافة أو مستودع GitHub ولا ترفع الكود نيابةً عنك. يلزم تسجيل الدخول إلى حساباتك وإتمام ربط Git وإعداد قاعدة الإنتاج من لوحة الاستضافة. النطاق الخاص مثل `wasl.com` خطوة اختيارية بعد حصول الموقع على رابط عام.
