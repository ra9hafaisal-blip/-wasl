# نشر وَصْل كرابط عام

المستودع موجود على GitHub، لكن `http://127.0.0.1:8000/` عنوان محلي لا يفتحه إلا جهازك. لنشر التطبيق وربطه برابط عام، اتبع الخطوات التالية في [Laravel Cloud](https://cloud.laravel.com/):

## إنشاء التطبيق

1. سجّل الدخول إلى Laravel Cloud بحساب GitHub الذي يملك المستودع، واسمح لـ Cloud بالوصول إلى المستودع `ra9hafaisal-blip/-wasl`.
2. اختر **New application** ثم المستودع `-wasl` والفرع `main`، واجعل مجلد التطبيق جذر المستودع.
3. أنشئ بيئة إنتاج واختر PHP 8.5. تأكد أن أوامر البناء والنشر هي:

   ```sh
   composer install --no-dev && npm run build
   php artisan migrate --force
   ```

## قاعدة الإنتاج والإعدادات

1. من موارد البيئة، أضف قاعدة **MySQL** مُدارة.
2. أضف متغيرات الإنتاج:

   ```text
   APP_NAME=Wasl
   APP_ENV=production
   APP_DEBUG=false
   APP_URL=<الرابط الذي تمنحه Cloud>
   DB_CONNECTION=mysql
   ```

   اترك Cloud يضيف بيانات اتصال قاعدة البيانات و`APP_KEY` تلقائيًا؛ لا تضعها في ملفات المشروع أو GitHub.
3. ابدأ النشر من لوحة Cloud. عند نجاحه ستعرض المنصة رابطًا عامًا ينتهي عادةً بـ `.laravel.cloud`. افتح الرابط وتحقق من الصفحات والتسجيل وإضافة البطاقات.

## ملاحظات قبل الإطلاق

- قاعدة الإنتاج جديدة؛ البطاقات في قاعدة SQLite المحلية لا تنتقل تلقائيًا. إذا أردت بطاقات عرض، راجع `QuoteDemoSeeder` ثم شغّله يدويًا بعد النشر فقط إذا كانت محتوياته مناسبة للنشر.
- لا ترفع `.env` أو قاعدة `database/database.sqlite` إلى GitHub. قواعد `.gitignore` تستبعدهما.
- كل تحديث تدفعه إلى `main` يمكن أن ينشر تلقائيًا بعد ربط المستودع.
- النشر يتطلب تسجيل دخولك إلى حساب الاستضافة وربط GitHub وإضافة قاعدة الإنتاج؛ لا تشارك كلمة المرور أو مفاتيح الأسرار. بعد اكتمال الإعدادات، اضغط **Deploy** لتحصل على الرابط العام.
